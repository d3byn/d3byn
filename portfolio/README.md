# Debayan Sarkar — Portfolio

Personal portfolio inspired by the layout and visual language of [aswinpanengal.me](https://www.aswinpanengal.me/), filled with Debayan’s resume content.

## Run locally

```bash
cd portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS + custom CSS matching the reference tokens
- Space Grotesk
- Lucide icons

Content source: resume TeX (`docs/debayan-resume-filled.tex` in the project store).
